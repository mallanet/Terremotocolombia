# Mallanet — assets oficiales

Fuente de verdad de la red **Mallanet.org**. No sustituir por trazos aproximados.

## Variantes

| Archivo | Fondo | Uso |
|---------|-------|-----|
| `isotipo-claro.svg/.png` | Oscuro (ink `#0f2154`, foto) | Favicon, app icon, chrome oscuro |
| `isotipo-oscuro.svg/.png` | Claro (papel, mist) | Headers claros, docs |
| `logo-claro.svg/.png` | Oscuro | Wordmark en OG / splash oscuro |
| `logo-oscuro.svg/.png` | Claro | Wordmark en UI clara |

## Tokens canónicos

- Blue `#4080f2`
- Ink `#0f2154`
- Mist `#e1eaff`

## Clearspace

Mínimo 0.25× altura del isotipo. Padding favicon ≥18 % del tile.

## Prohibido

- Recolorear el wordmark custom
- Usar Epicentro (producto) como favicon
- Combinar con escudos de Estado o semiótica de campaña
- Crédito a GlobalEmergency u otras redes
